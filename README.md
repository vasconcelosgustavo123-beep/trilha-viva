# Trilha Viva Learning Club

Crie a plataforma completa de estudos, quizzes e gamificação com base no meu protótipo anexado (plataforma-estudos-quiz.html), consertando e evoluindo para uma aplicação web moderna com backend:

- Autenticação real com verificação de e-mail enviando código/confirmação para a caixa de entrada real (sem simulação de alert na tela).
- Trilhas de estudo por matérias (Português, Matemática, Física, Química, Inglês), com tópicos/aulas estruturados com texto teórico explicativo, vídeo-aula incorporado, leitor/download de PDF e quiz de 10 questões somando pontos ao perfil.
- Lista geral de atividades em ordem sequencial com suporte a imagem no início da pergunta.
- Painel de edição do admin igual ao Quiz Party Creator para criar e editar perguntas, matérias, imagens, vídeos, PDFs e personalizar cores do tema.
- Perfis de usuário com avatar personalizável, ranking gamificado com pódio dos líderes e reações com emojis e comentários curtos.
- Sistema de denúncias para moderar jogadores e comentários, com fila de análise no painel administrativo para arquivar ou banir.
- Espaços de publicação e privado para os próprios projetos e quizzes dos usuários (como no Space Path Creator), permitindo rascunhos particulares ou publicação para toda a comunidade.
- Criação de grupos personalizados entre pessoas selecionadas, além do chat aberto do Grupo Geral e mensagens diretas com controle de autorização prévia.
